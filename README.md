# Synapse Engine ⚡

> **The Constitutional Visual IDE & Blueprint Engine for Next.js 15 & React 19**

Synapse Engine is a visual development studio where complex Next.js applications are constructed from atomic, typed, pure functional micro-nodes enforced by an in-browser Lisp and Clojure Spec constitutional engine.

---

## Key Features

- 📐 **Blueprint Dataflow Canvas**: Visual node graph powered by `@xyflow/react` with Unreal/Blender domain hierarchy headers (`physics/*`, `chess/*`, `ui/*`, `io/*`).
- 🛡️ **Clojure Spec Constitutional Gatekeeper**: Live AST evaluation enforcing strict functional laws ($\le 30$ lines, zero mutation `let`/`var`, zero `this`).
- 🔌 **Strict Zod Wire Contracts**: Visual handles typed and validated by Zod schemas with instant compatibility checks.
- ⚡ **Native Next.js 15 & React 19**: Direct execution inside modern App Router — no outdated HTML runtime string-bundles or `innerHTML` hacks.
- 🎨 **Rich Dark Design Tokens**: Tailored HSL color spaces, glassmorphism, and seamless high-res textures.

---

## Quick Start

```bash
# Install dependencies
bun install

# Run unit tests (Lisp engine, AST metrics, Zod contracts)
bun test

# Start the dev server
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
